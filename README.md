## Projects

### [BarberFlow](../barberflow)

Telegram booking system for barbershops.

Client booking, appointment management, administration and automated reminders built around a Go backend and PostgreSQL.

### [RepoPulse](../repopulse)

Backend service for asynchronous synchronization of GitHub repository statistics.

REST API, PostgreSQL-backed job processing, bounded worker pool, retry handling and integration with the GitHub REST API.

### [cpp-http-server](../cpp-http-server)

HTTP server implemented in C++17 using POSIX sockets.

Includes HTTP parsing, routing, middleware pipeline, static file serving and a ThreadPool.
